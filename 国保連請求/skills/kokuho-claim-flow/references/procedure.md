# マニュアルに基づく操作手順

出典: ユーザー提供「国保連請求 操作マニュアル.pptx」全29枚。原資料表記はTango手順書、2025年12月10日作成・36ステップ。記載の2025年11月・25名は例示。以下はテキスト抽出に基づく手順であり、現行画面での実機検証済み手順ではない。

STEP 1–8は2026-09-25のユーザー補足と実機検証により具体化済み。[ダウンロードルール](download-rules.md) と [ダウンロードフロー](download-flow.md) を優先し、川島・沖洲それぞれA・B一括の1組ずつを取得する。

| STEP | 操作と確認 | スライド |
|---|---|---|
| 1–2 | ラクコ上部の「帳票出力」から「請求書類」を開く | 5 |
| 3 | 対象月を設定し、対象利用者数を確認 | 6 |
| 4–6 | 「利用者を選択する」→通常は「すべて選択」→「決定」。除外者がいる場合は指定対象と照合 | 7 |
| 7 | 「請求書類を作成」。ダウンロード・印刷一覧に対象月の行が追加されたことを確認 | 8 |
| 8 | 同じ行の提出用CSV「請求書」「実績記録票」を取得。CSVを編集しない | 9 |
| 9–12 | 取込送信V2を起動し、事業所番号を選択してログイン | 11–12 |
| 13–14 | 「請求情報取込/送信」。請求年月日・請求事業所を確認 | 13–14 |
| 15–16 | 「介護給付費等請求書・明細情報」にチェックし「参照」で請求書CSVを選択 | 14–15 |
| 17–18 | 「サービス提供実績記録票情報」にチェックし「参照」で実績記録票CSVを選択 | 16 |
| 19–20 | 2ファイルの対応を確認し「実行」→確認メッセージ「OK」 | 17 |
| 21–23 | 電子請求受付システムのユーザIDを確認してログイン | 18 |
| 24–25 | 請求年月・情報名・送信件数・エラー件数を確認。エラー0件と承認を確認して「送信」→「はい」 | 19 |
| 26 | 「正常に到達しました」と到達番号を確認 | 20 |
| 27–28 | 「印刷」→「Microsoft Print to PDF」で到達確認を保存 | 21 |
| 29 | 到達確認PDFを所定フォルダへ保存 | 23 |
| 30–33 | ラクコの印刷用PDF「実績記録票」→「印刷する」→「PDFに保存」、ドライブへ保存 | 24–25 |
| 34–36 | ラクコの印刷用PDF「請求書」→「印刷する」→「PDFに保存」、ドライブへ保存 | 26–27 |

2026-09-25の最新ユーザー手順では、送信後に認証情報選択画面で営業所（沖洲／川島）を対応させて選び、直後の結果を確認してエラーを報告する。標準はここで終了し、PDF・Drive保存は依頼時のみ行う。STEP 13以降の実行判断は [取込・送信ルール](import-send-rules.md) と [取込・送信フロー](import-send-flow.md) を優先する。資料中の「はい」を未観測画面に当てはめない。

## 保存先

親フォルダ: `2_業務関連 > 08_国保連請求`。初回に対象事業所と実際のフォルダIDを確認する。

| PDF | 子フォルダ |
|---|---|
| 到達確認 | `01_到達確認` |
| サービス提供実績記録票 | `02_請求書類　サービス提供実績記録表` |
| 請求書・明細書 | `03_請求書類　請求書・明細書` |

到達確認のマニュアル例は `2025.11月到達確認.pdf`。実行対象に置換し、命名に使う月が提供月か請求月かを既存運用で確認する。事業所や再送回の違いで同名になる場合は、事業所番号・到達番号等で識別し、既存ファイルを上書きしない。

上限額管理結果票は「必要な場合のみ取得」とあるが、要否の条件や取込詳細は本資料にない。該当する場合は通常2ファイルだけで完了とせず、確認済みの追加手順をユーザーに確認する。過誤・返戻再請求も資料外のため、既存の承認済み手順がなければ質問する。
