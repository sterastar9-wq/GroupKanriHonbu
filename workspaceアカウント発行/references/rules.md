# 発行・同期ルール

## 対象と接続

- 台帳: https://docs.google.com/spreadsheets/d/1yoxdYjMy62BAlLG0iH8chQXKEJWl-8rw/edit?gid=772961413#gid=772961413
- タブ: 社員情報台帳、gid `772961413`。
- 管理コンソール: https://admin.google.com/ 。認証パラメータ付きURL・トークンを保存しない。
- 確認時テナントは `stera rehope 株式会社`、プライマリドメインは `sterarehope.com`。作成対象はセカンダリドメイン `steragroup.co.jp`。毎回確認する。
- 既存Chromeタブを使用する。台帳と管理画面が別プロファイルの場合は各接続を保持する。作成フォームは同じタブで準備し、入力中の画面を再読み込み・移動して消さない。
- 2026-09-29時点の台帳はExcelマクロ付き `.xlsm` のGoogle Office編集画面。同形式ならブラウザで編集し、ネイティブSheets APIへ渡さず、変換・置換・全体再アップロードもしない。ネイティブSheetsに変わっていれば利用可能なDrive/Sheets連携を使用できる。

## 入力と列対応

社員番号と氏名のタブ区切り・改行・空白区切りの貼り付けを受け付ける。社員IDは文字列として先頭ゼロを保持する。貼り付けでゼロが落ちた場合、一意の本人照合後に台帳表記へ戻す。姓名・ローマ字のユーザーによる明示訂正を優先し、依頼された訂正の反映を検証する。

確認時は見出し6行目、社員7行目以降。行番号を固定せず、毎回見出しと社員ID・氏名を確認する。

| 列 | 内容・扱い |
| --- | --- |
| A | 社員ID。一意の本人照合と初期パスワードの接頭部 |
| B | 氏名。姓・名を分割。矛盾があれば勝手に氏名を改訂しない |
| C | フリガナ。読み確認 |
| D | ローマ字。名.姓の根拠。空白区切りでも姓名順を確認 |
| E～H | 法人・部署・拠点等。必要な範囲で本人照合 |
| M・N | 退職日・在籍状況。対象性を確認 |
| AB | Google Workspace。「有」「無」の既存規則を使用 |
| AC | workspaceアカウント。確認済みの完全なメール |
| AD | その他主要アカウント。変更しない |
| AE・AF | 最終更新日・更新者。実更新日と `Codex` を記録 |
| AG | 備考。既存内容を保持 |

新規メールは半角小文字の `[名のローマ字].[姓のローマ字]@steragroup.co.jp`。D列と氏名・フリガナが矛盾する、読みが未確定、姓名分割が曖昧なら必要な点だけ確認する。長音等を推測で確定しない。D列の補完・訂正は依頼範囲で行う。

## 重複・衝突

- AC空欄やAB「無」だけで未発行としない。管理画面の全組織部門・ページ・フィルタを確認する。
- 氏名、既存・予定アドレスで照合し、必要ならエイリアス・グループの衝突を調べる。
- 本人の既存アカウントなら規定と違っても作り直さず、AB・ACの欠落を実在値で補完する。
- ACの相違、別人の同名、旧姓、停止中・削除済み等で判断できなければ当該者だけ保留する。独自の数字追加、復元・停止解除・改名はしない。
- 退職者・対象不明なら発行を保留する。ライセンス不足は実画面で確認し、勝手に購入・契約変更しない。管理者権限・グループ所属を推定で付与しない。

## パスワードと役割分担

- 規定は `社員ID（先頭ゼロを保持） + 名のローマ字 + . + 姓のローマ字`。空白や @ドメインは付けない。
- 社員ID・氏名・メールを表示し、パスワードだけを単独コードブロックに入れる。1人ずつ対応付ける。
- エージェントは姓名、メールのローカル部、対象ドメイン等を入力し、手動パスワード欄が使用できる状態まで準備する。
- 「初回ログイン時にパスワード変更を必須」にする。資格情報入力前に選べるならエージェントが選択して状態を確認する。入力後にしか選べなければユーザーへチェックを依頼する。未確認の設定を完了と報告しない。
- ユーザーがコピーし、パスワード入力・確認・最終作成を担当して報告する。ブラウザ操作の認証情報変更に関する引き継ぎ要件に従い、別ツールやフルアクセスで入力を迂回しない。
- 表示だけでは設定された証拠にならない。この手順での作成完了報告はユーザー申告として案内文の根拠にできる。別の値を使った場合は以前表示した値を配布しない。
- パスワードをスキル・台帳・作業ファイル・通常ログへ平文保存しない。この対話のコピー用表示・依頼された案内文と外部配信を区別する。

## 完了条件

管理画面で本人・完全なメール・状態を確認し、台帳を再読してAB「有」、AC実アドレス、AE実更新日、AF「Codex」を必要なセルだけ更新する。一致済みのセルは不要に書き換えない。保存済み表示と読み戻しを確認する。発行成功・台帳失敗なら再作成せず同期から再開する。
