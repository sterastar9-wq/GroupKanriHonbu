# Google Workspace 従業員アカウント発行・台帳同期

実行時は [ルール](references/rules.md) と [実行フロー](references/flow.md) を読む。社員番号と名前の貼り付けを、その対象者の発行準備として受け付ける。スキル作成だけの依頼では本番操作しない。

## 通常の進め方

1. 社員番号・氏名を台帳と照合し、ローマ字と既存アカウントを確認する。
2. 未発行者だけ管理コンソールの作成フォームをパスワード入力直前まで準備する。同じ作業タブを使用し、実画面を確認してから準備完了と伝える。
3. `社員ID + 名のローマ字 + . + 姓のローマ字` の初期パスワードを1人ずつ単独のコードブロックで表示する。ユーザーがコピーして入力・作成する。実際のパスワード入力・確定はエージェントで代行しない。
4. 「作成した」「次」「全員登録できた」等の報告を受けたら、対象者の登録を管理コンソールで確認する。
5. 確認した実アドレスを台帳へ反映し、保存・読み戻し後に完了を通知する。複数名なら残りの対象者へ進む。

## 報告

- 既存アカウントは重複作成せず、記載漏れだけ補完する。
- 作成操作の報告、登録確認、台帳保存完了を区別する。結果不明のまま再作成しない。
- コピー用表示と依頼された本人向け案内文には初期パスワードを含める。通常の完了サマリー・保存ファイルには秘密値を含めない。
- 本人向け案内には氏名、メールアドレス、設定した初期パスワード、初回ログイン時の変更依頼を揃える。規定値と設定済みの値を混同しない。外部送信は別途明示依頼がある場合のみ。

## 検証履歴

2026-09-29に既存Chromeで6名の登録を確認し、台帳のAB・AC・AE・AFを更新して読み戻しと保存完了を確認した。パスワード入力はユーザーが担当した。本スキルは対話で再開する手順であり、常駐処理・自動監視を登録したものではない。メール送受信・本人ログイン・全員の初回変更強制設定は確認済みと扱わない。
