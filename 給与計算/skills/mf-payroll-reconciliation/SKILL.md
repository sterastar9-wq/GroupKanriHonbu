# 給与照合

[総合フローの02・03](../../00_給与計算総合フロー_v1.0.md)と[計算ルール](../../rules/給与計算ルール.md)を読む。認証は隣接rakuco-login-sessionスキルを使用する。

1. 法人、勤怠月、支給日、対象者集合、資料時点を固定する。
2. 原本の実働・休憩・出勤日数とMFの実働・休暇みなし・無給欠席を区別し、文字列IDと氏名で照合する。
3. 基本給・通勤・役職・資格・処遇改善について現在値、期待値、差、根拠、未確認理由を記録する。空欄を0としない。
4. 照合依頼だけでは変更しない。変更依頼がある場合のみ修正し、保存後の値を確認する。
5. 支払対象者だけを照合・修正後に確認済にする。人数だけでなくMF番号の集合で全員の確認を検証する。
6. 未解決事項がなくなった後、給与確定は依頼者へ引き継ぐ。確定しないテストでは実行しない。振込は範囲外。
