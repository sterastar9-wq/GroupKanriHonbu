# 確定給与FB加工

[詳細フロー](../../01_確定給与データ加工・引渡しフロー_v1.0.md)を読み、[共通ルール](../../AGENTS.md)を適用する。

給与振込、既定レコード設定、指定支払口座で作成ボタンを一度押す。自動ダウンロードを待ち、元のファイル一覧との差、保存時刻、サイズ、ZIP展開で取得を判定する。取得リンクを追加で開かない。ブロック時は停止報告する。

TXTの銀行・支店・預金種目・口座・カナ・金額と、CSVのID・氏名を組み合わせ、一対一対応と本人を確認する。候補複数、拠点空欄、矛盾なら出力前に停止する。

5区分に分割し、TXTのみ種別11→21、120バイト・Shift-JIS・CRLF、トレーラ再計算。6列の銀行用CSVには種別欄がない。保存後に再読込し、欠落・重複なし、総件数・金額一致を確認する。個別例外は外部の承認済み設定で管理する。

個人例外を内蔵したローカルの試験用スクリプトは同梱していない。実装が詳細フローと異なる場合は事前報告し、修正指示を受ける。銀行アップロード・送信は実行しない。
