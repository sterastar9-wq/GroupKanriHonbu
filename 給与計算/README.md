## スキル

skills/の各フォルダをCodexのスキル配置先にコピーして利用できます。フローへの相対参照を保持するため、給与計算ディレクトリ全体を作業資料として利用してください。単独コピー時は参照先をこのディレクトリへ設定し直してください。

- rakuco-mf-punch-export：原本取得、全行検証、承認済みCSVのMF取込。build_candidate.pyと検証契約を同梱。
- mf-all-sites-csv-merge：検証済み拠点別CSVの統合。
- mf-attendance-timesheet-export：MF出勤簿の取得。
- mf-payroll-reconciliation：給与と各手当の照合、確認済・確定への引継ぎ。
- rakuco-login-session：承認済み.envによる認証。
- mf-payroll-fb-handoff：確定給与FBの照合・加工・5分割引渡し。

## 実行環境に別途必要なもの

承認済み認証用.env、最新利用者マスタ・社員台帳、原本勤怠、個人別手当・旧姓・振分例外と適用期間。実行データはリポジトリ外またはGit除外済みprivate/runs/outputsで管理し、pushしない。

本資料の保存は本番操作の実行許可や全工程合格を意味しません。既存の個人情報入りFB試験コード、月固定の監査スクリプト、個人別結果は含めていません。ソース変換スクリプトの年月形式・列構成が実原本と合わない場合は停止報告し、検証した変換仕様を用意してから使用します。
